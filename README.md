## Beyond the Code
Before and alongside my studies, I have worked in compliance and healthcare, where I've done data auditing and validation, internal systems management, and process standardization. At my current job, I replaced a paper-based tracking system with a spreadsheet tool that flags missing and expired documents, and my whole team adopted it. That experience shapes how I build software: I start by asking what the person using it actually needs.

My interests include back-end and full-stack development, database systems, automation, and machine learning.
